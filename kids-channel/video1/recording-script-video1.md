# Video 1: Fruits in 3 languages. Voice recording script

Three characters, three voices. Record each character in ONE go, in order, leaving about 2 seconds of silence between lines.
Quiet room, phone about 15-20 cm from the mouth, no music. Playful, smiling, bright, like talking to a 3-4 year old. Speak a little slower than normal and finish every line cleanly.
Name the files: PENGUIN_english.m4a, BONBON_french.m4a, CHURRO_spanish.m4a (any common format is fine).

Penguin name is still a placeholder (Milo). If you change it, change the first line.
