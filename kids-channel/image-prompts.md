## F. Tips for new scenes
- Always pass the group image (MAHXci5Ijs0) as the image reference so the characters, accessories and colors stay consistent.
- Keep the accessories in every prompt: bunny = black beret between the ears + red-and-white striped scarf; bear = colorful sombrero; penguin = red baseball cap.
- Check each image at full size before using it (fruit correctness, accessories, hands/positions).
- Prompt template for Gemini, Picsart or others: "Three adorable baby animal friends (baby bunny, baby bear cub, baby penguin), flat 2D cartoon, very big round heads, big glossy eyes, rosy cheeks, thick soft outlines, sky-blue background, bunny with black beret and red-and-white striped scarf, bear with colorful sombrero, penguin with red baseball cap, pointing at [fruit], no text."
