# Trilingual kids channel (English / French / Spanish)

Characters: Bonbon (white bunny, French, beret + striped scarf), Churro (brown bear, Spanish, sombrero),
Milo (blue-and-white penguin, English, red cap; name is a placeholder).

- `plan.md`: research, characters, voices, video 1 script, 10-video plan, risks, open decisions
- `image-prompts.md`: early Canva prompts (character selection, first fruit scenes)
- `video1/free-animation-pack-video1.md`: the 12 Canva scene links and one motion prompt per scene (free tools)
- `video1/reel-story-prompts-video1.md`: 9:16 story version with gags
- `video1/recording-script-video1.md`: lines to record for each character
- `video1/video1_fruits_subtitles.srt`, `video1/video1_voice_timing.csv`: subtitle colors/timing and voice timing
- `video1/build/build_free.py`: ffmpeg script that builds the 16:9 draft from 12 stills (`stills/s01.png` ... `s12.png`)

Images and videos are not stored here (large). The 12 stills live in the Canva design "Fruits video 1 - stills".
